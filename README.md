One dad joke, told the way a father would tell it at the dinner table:
**"I sat down to have a serious talk with the chair. It said, "Dad, I can't
stand this conversation any longer.""** Fourteen original candidate jokes were
drafted on distinct topics and scored against the judge's five criteria in
order, then the top three went before an independent three-model judge panel
(deepseek-v4-flash, gemma-4-31b-it, grok-4.7-fast), which picked the chair joke
unanimously on combined score — 396 vs 373 (cheese) vs 344 (spaghetti) — and
overruled the internal winner: two judges independently flagged that the
spaghetti joke's "ends meat" pun only works on paper, not spoken aloud. See
`../candidates.md` for the full candidate list, scores, and the panel verdict.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
